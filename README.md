# HTML-CANVAS-තොරණ (React Component Based)

This repository is now converted to a React + Vite project.

The thorana canvas animation is implemented as a React component with:
- React state-driven controls (colors, speed, density, bulb size, glow, scale)
- Canvas rendering and animation loop handled in React lifecycle (`useEffect`)
- Responsive canvas resizing

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Lint

```bash
npm run lint
```
